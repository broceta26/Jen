# Jen konverter

Jen (JPY) u evro, američki dolar i dinar po fiksnom kursu. Instalira se na telefon kao web aplikacija (PWA): otvori stranicu u Chrome-u, pa meni ⋮ → „Dodaj na početni ekran“ / „Instaliraj aplikaciju“.

- `index.html` – aplikacija (kursevi su u konstanti `FIXED` u skripti; promeni brojeve i datum zajedno)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` – instalacija i rad bez interneta
